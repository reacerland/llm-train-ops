# trainops mix 工具实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 `trainops mix` 命令：按 TOML 配置将多个 convert 产出的 Arrow 数据集，用配置指定的 tokenizer 编码、按比例的文档级不放回加权抽样打包成定长 token 序列，落盘 `tokens.bin` + `meta.json`，训练循环零加工直接 memmap 加载。

**Architecture:** 两阶段流水线：逐源预 tokenize 到临时 `.bin`（uint32 token 流 + uint64 文档偏移边车），再混合打包（固定 seed 的加权不放回抽样 → 连续流按 `max_seq_len` 硬切）。纯逻辑（配置解析、抽样打包）与 IO（Arrow 读取、临时文件、写盘）分层，各自可单测。鸭子类型 tokenizer 接口支持预置名与自定义 Python 类文件两种形态。

**Tech Stack:** Python ≥ 3.10、typer、numpy（datasets 传递引入，不新增显式依赖）、datasets/pyarrow、`tomllib`（3.10 用 `tomli` 兜底）、pytest。

**Spec:** `docs/superpowers/specs/2026-10-13-mix-tool-design.md`（本计划所有语义以它为准）

## Global Constraints

- Python ≥ 3.10；TOML 用 `tomllib` 标准库，导入兜底：
  ```python
  try:
      import tomllib
  except ModuleNotFoundError:  # Python 3.10
      import tomli as tomllib
  ```
- 不新增显式 numpy 依赖（datasets 已传递引入）；`tomli; python_version < "3.11"` 与 extras `hf = ["transformers>=4.40"]` 在 Task 6 加入 pyproject
- 退出码：成功（含源抽干停止）= 0；错误 = 1；CLI 用法错误 = 2。沿用 `cli.py` 的 `os._exit` 机制与 `typer.secho(err=True, fg=RED)` + `typer.Exit` 模式
- 配置默认值（来自 spec）：`subset="default"`、`split="train"`、`field="text"`、`seed=42`；`max_seq_len` 必填；`ratio > 0`；比例不归一化
- dtype 规则：`vocab_size < 65536` → `uint16`，否则 `uint32`
- meta.json 顶层含 `"format": "trainops-mix/v1"`
- 所有测试不得联网：预置 tokenizer 一律 mock/注入 fake，不新增 slow 测试
- 测试风格沿用现有 `tests/`：tmp_path fixture、直接调 `run_*` 函数 + `typer.testing.CliRunner` 测 CLI

## Review Focus

1. **比例不归一化**（配置写 `ratio = 7` / `ratio = 3`）：必须合法且行为与 0.7/0.3 等价——Task 3 有测试钉住
2. **源全部为空文档**（多行但 tokenize 后全空）：必须在 pretokenize 阶段明确报错，不能表现为静默抽干——Task 4 有测试钉住
3. **同配置两次运行逐字节一致**：Task 5 有测试钉住（同一 numpy 版本内；numpy 不承诺跨版本 bit 流一致，spec 的同配置可复现按同环境理解）
4. **自定义 tokenizer 谎报 vocab_size**（声称 < 65536 却发出更大 id）：写 uint16 前必须检查溢出并清晰报错，不能产出损坏 tokens——Task 5 有测试钉住
5. **选了预置 tokenizer 但未安装 transformers**：报错信息必须包含 `pip install trainops[hf]`——Task 2 有测试钉住

- [ ] **Step 3: 实现 `pack.py`**

算法（spec 钉死，照此实现）：

```python
names = list(streams)                      # 固定顺序，保证确定性
probs = np.array([weights[n] for n in names], dtype=float)
probs /= probs.sum()
buffer: list[int] = []

def flush_full() -> None:
    while len(buffer) >= seq_len:
        sink(buffer[:seq_len])
        del buffer[:seq_len]
        result.sequences += 1
        result.tokens_written += seq_len

while True:
    name = names[rng.choice(len(names), p=probs)]
    try:
        doc = next(streams[name])
    except StopIteration:
        result.exhausted_sources.append(name)
        break
    buffer.extend(doc)
    per_source[name].docs_sampled += 1
    per_source[name].tokens += len(doc)
    flush_full()
flush_full()                               # 停止时先冲刷完整序列
result.dropped_tail_tokens = len(buffer)
```
